# Sketch 001: Copilot Chat Directions

## Design Question
Which conversation structure makes Copilot feel useful and dynamic inside the openable right-side Plan panel, without exposing internal reasoning?

## How to View
Open .planning/sketches/001-copilot-chat-directions/index.html in a browser. Select A, B, or C from the tabs or use the bottom-center arrows. The page also accepts ?variant=A, ?variant=B, or ?variant=C.

## Variants
- A: Chat-first — familiar transcript, inline suggestions, and a fixed composer.
- B: Research workspace — conversation beside a live, evidence-backed shortlist.
- C: Guided trip — focused prompt and traveler choices in a concierge-style sequence.

All message sending, progress, source expansion, and save actions use simulated sample behavior. No provider, database, or agent call is made.

## What to Look For
Compare how quickly each layout explains what Copilot is doing, how easy it is to keep the Plan/map context visible, and how clearly a traveler can decide whether to save a destination.
