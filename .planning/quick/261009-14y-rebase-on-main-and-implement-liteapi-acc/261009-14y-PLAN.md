Freeze this snake_case contract before backend/frontend parallel work. The backend owns services, scripts, and compose; frontend owns frontend/src. Parent owns artifacts and final wiring review. No lane edits another lane's files without coordination.

All public routes use prefix /v1/agent/plans/{plan_id}/travel, both at the BFF and Agent. GET /capabilities returns {provider:"LiteAPI", sandbox:boolean, hotels:boolean, flights:boolean}. Availability reflects configured/account capability, never an assertion that production inventory is enabled. The browser can hide unsupported modes and displays a useful unavailable screen if an already-open mode becomes unavailable.

GET /airports?q=... returns {status, airports:[{iata,name,city,country_code}], provider:"LiteAPI", sandbox}. Query is trimmed, 2–80 characters, debounced and bounded. Connector uses the official flight-airport endpoint confirmed by the research lane; never the similarly named third-party travel.tech API. Selecting a suggestion supplies the IATA code; an unselected free-text value cannot be submitted as a code.

POST /hotels/search accepts {destination:{city?,country_code?,latitude?,longitude?},check_in,check_out,rooms:[{adults,children_ages:[]}],guest_nationality,currency,hotel_id?}. Require either city plus ISO country or a valid coordinate pair, ISO exact dates with check_out after check_in, bounded occupancies, ISO nationality/currency, and only known fields. Prefill trusted Plan destination/party/date hints when available; require missing exact values and confirmation through submit. Do not guess nationality from residence or destination. Optional hotel_id narrows the same stay search for room choices and must be syntax/bounds validated. Search destination changes remain transient and do not mutate the Plan.

GET /hotels/{hotel_id} returns {status,provider,sandbox,hotel:{hotel_id,name,description,address,latitude,longitude,stars,review_score,review_count,images:[{url,caption}],facilities:[]}}. Description is plain text, images are bounded safe HTTPS URLs, absent fields are null/empty. No raw HTML execution. Details screen requests rich content and same-criteria hotel_id search; room data is not inferred from static room descriptions.

POST /flights/search accepts {origin,destination,departure_date,return_date,adults,children_ages:[],infant_ages:[],cabin_class,currency,country_code}. origin/destination are confirmed IATA values; enforce distinct endpoints, return-only ordered exact dates, age categories and bounded party size. Connector translates to LiteAPI legs:[{origin,destination,date,direction:"OUTBOUND"},{origin:destination,destination:origin,date:return_date,direction:"INBOUND"}], adults, children, infants, childrenAges, infantAges, cabinClass, currency, country. Do not forward undocumented top-level departureDate/returnDate provider fields.

Search success envelope is {status:"ready"|"empty",provider:"LiteAPI",sandbox:boolean,searched_at:ISO_UTC,results:[],returned_count:number,truncated:boolean,notices:string[]}. A complete empty result is distinct from upstream failure. Unavailable provider errors return sanitized 502/503/504 {code,message}; authorization 401/404, validation 422. The UI preserves the previous complete response on failure. No credentials, raw provider payloads, offerId, rateId, booking/session/payment handles, supplier deep links, or internal exception strings appear in responses.

Hotel result: {id,hotel_id,name,address,latitude,longitude,stars,review_score,review_count,image_url,price:{amount,currency,basis:"stay",excluded_taxes:[],estimated:boolean},rooms:[{id,name,board_name,refundable:boolean|null,cancellation_summary,cancellation_deadline,total:{amount,currency},excluded_taxes:[{name,amount,currency}],occupancy_summary}],facilities:[]}. Amounts are decimal strings or null, not fabricated zeros. id is a local result identifier, not a provider offer token. Cancellation deadline retains the supplied timezone. Show full-stay total; per-night cost is a labeled arithmetic derivation only. Unknown terms say not supplied.

Flight result: {id,price:{amount,currency,basis:"party_return",estimated:boolean},airlines:[],outbound:{duration_minutes,stops,segments:[]},inbound:{duration_minutes,stops,segments:[]},baggage_summary,refundable:boolean|null,cancellation_summary}. Segment: {origin,destination,departure_at,arrival_at,airline,flight_number,duration_minutes,technical_stops:[]}. Respect offset-bearing/local timestamps; do not falsely format provider-local times as UTC. Stops include technical stops as well as connections. Baggage unknown is not zero baggage. Distinguish marketing and operating carrier when provided. Detail expands this normalized record; no flight prebook/verify call is needed for research-only inspection.

Bound provider calls and response sizes, request at most a sensible hotel subset and cap normalized journeys. Preserve truthful truncated/notices labels, e.g. sorting/filtering the returned sample. Search, Refresh results, Apply filters, and Retry are explicit actions; provider requests do not run on every keypress (only debounced airport lookup). Sorting may reorder the already returned set without provider calls. Abort or generation counters prevent old search/detail/autocomplete responses leaking into the current mode or Plan. Search state stays ephemeral and separate from canvas dirty/save state.
