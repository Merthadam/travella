# Reliable local startup and authentication

## Goal

Make it easy to start the local single-container app and distinguish startup failures from invalid example-user credentials without exposing the password or tokens.

## Tasks

1. Add a startup wrapper that starts the existing local Compose stack detached, waits for frontend and configured-auth health, then runs one sanitized example-account sign-in/session/sign-out smoke check.
2. Add a focused project skill documenting the canonical localhost origin, startup command, browser follow-through, safe failure diagnosis, and password/session safety; update local-development docs to point to it.
3. Run focused checks for the script and verify it against the running local stack.

## Boundaries

- Read the example account from `~/.config/travella/test-account.json`; never print/store the password, cookies, or returned tokens.
- Perform a single Cognito sign-in attempt per check, no automatic retries or password reset.
- Keep the database volume and existing user data intact.
