# Plan 11-01: Define the isolated Claude research worker and skill contract

## Objective

Add the SDK dependency and implement a narrow, testable adapter that invokes one bounded research task and returns only a validated result.

## Tasks

Decision coverage: D-01: LangGraph stays the supervisor; D-02: later stages stay graph nodes; D-03: the worker is stateless across turns; D-04: use the Agent SDK research tools and travel skill; D-06: bound research; D-11: retrieved text stays untrusted; D-12: use the Secrets Manager supplied Anthropic key; D-13: keep other model calls as configured.

1. Pin a compatible `claude-agent-sdk` dependency in `pyproject.toml` and regenerate `uv.lock`. Verify the bundled CLI/runtime requirements and select a supported release for Python 3.12 and the AgentCore ARM64 image.
2. Define a strict typed result contract for answer text, read-source citations, uncertainty, and optional existing destination candidate references. Reject unknown/oversized fields and invalid source URLs.
3. Implement an injectable async worker adapter using SDK one-shot `query()`, explicit web tools, explicit `travel-research` skill, controlled project settings, bounded turns/time/cost/output, and no session resumption.
4. Add `.claude/skills/travel-research/SKILL.md` with domain behavior only; verify runtime packaging and avoid skill instructions that imply security controls.
5. Add deterministic adapter tests for normal results, tool/source normalization, unavailable reads, malformed structured output, SDK errors, limits, and sensitive data redaction.

- `uv run ruff check services/agent/claude/research_worker.py services/agent/claude/research_result.py services/agent/tests/test_research_worker.py`
- Verify locked dependency resolves for the project Python constraint and inspect final SDK options to ensure capabilities are truly restricted.
