# Plan 11-02: Integrate the worker with LangGraph state and chat output

## Objective

Replace the existing research synthesis execution with the isolated SDK worker while preserving Phase 10 behavior and LangGraph ownership.

## Tasks

Decision coverage: D-05: preserve Phase 10 evidence behavior; D-07: keep destination candidates and traveler selection; D-08: LangGraph owns streaming and cancellation; D-09: validate result and citations; D-10: checkpoint only compact normalized state; D-14: keep the frontend contract unchanged.

1. Inject the worker through the existing adapter interface; keep ordinary conversation/model behavior and AgentCore Gateway candidate/map tools on their current paths unless the research contract requires a narrow change.
2. Have the graph research node provide bounded recent chat and relevant Plan context, invoke the worker, validate results, update compact state, and finish the graph research stage. SDK owns refinement; the graph must not repeat worker invocations.
3. Preserve candidate results for discovery requests; prevent any worker result from directly creating, selecting, or mutating durable Plan data.
4. Filter SDK messages so tool use, search traces, intermediate text, and errors do not leak. Stream only the final answer through the existing text callback; validate and attach citations using observed read-source provenance.
5. Propagate graph cancellation to the SDK subprocess and ensure late completions fail the existing run/generation checks.
6. Extend graph, service, and API tests for factual research, discovery, source read status, conflicting facts, unavailable sources, prompt injection, malformed output, cancellation, and no private payload projection.
