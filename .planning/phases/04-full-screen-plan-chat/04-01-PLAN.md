<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → auth service | Session-authenticated chat input and cancellable response stream. |
| Auth proxy → Agent | Validated bearer identity and Plan-scoped request. |
| Agent/model/tool output → browser | Only assistant prose and allow-listed source references may cross. |
| Agent → CRUD | Authorized server-to-server persistence of complete/stopped/interrupted messages. |

## Threat Register

| Threat | Severity | Mitigation |
|---|---|---|
| Cross-Plan message or stream disclosure | High | Derive traveler identity from token, validate Plan ownership before model work, bind every stream to Plan/event generation. |
| Internal context/reasoning/tool leakage | High | Strict event allow-list; reject or suppress all non-text provider/graph events. |
| Duplicate requests create duplicate turns | High | Preserve event receipt reservation and CRUD unique event ID semantics. |
| Late chunk appears after Stop or retry | Medium | Abort upstream when possible and always reject chunks from canceled/superseded generation. |
| Provider-supplied unsafe citation URL | High | Render only schema-validated HTTPS source references from the current Agent evidence allow-list. |
| Partial reply shown as complete | Medium | Persist/render explicit `complete`, `stopped`, or `interrupted` message status and test disconnect boundaries. |
</threat_model>
