# US-001 — Access a private Travella account

## User story

As a traveler, I can create an account or sign in so I can securely access only my own saved plans, conversations, and selected travel options.

## User flow

1. The traveler opens Travella.
2. A new traveler creates an account; an existing traveler signs in with email and password.
3. A new account verifies its email.
4. If enabled, the traveler completes authenticator-app two-step verification.
5. Travella starts an authenticated session and opens **My plans**.

## In scope

- Registration with first name, last name, email, and password.
- Email verification.
- Email/password sign-in.
- Optional authenticator-app two-step verification.
- An authenticated session for the traveler.
- Access only to the traveler’s own plans, conversations, and selected options.

## Out of scope for this story

- Password recovery.
- Profile editing.
- Social sign-in.
- Phone-number collection.
